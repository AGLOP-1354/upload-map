# 유튜브 도메인 용어

앱 코드와 콘텐츠 스킬이 같은 단어를 쓰도록 하는 기준. 단계 이름·KPI 이름은 여기 정의된 영문 키를 코드/JSON에서 그대로 쓴다.

## 제작 단계 (`VideoStatus`)

| key | 의미 | 다음 단계로 가는 조건 |
|---|---|---|
| `idea` | 백로그. 한 줄 아이디어 | 필러(pillar) 지정 + 시청자 약속 한 문장 |
| `research` | 자료조사·레퍼런스 영상 수집 | 브리프 작성 |
| `scripting` | 대본 작성 | 훅 확정(점수 STRONG/WORKABLE) + 대본 초안 |
| `packaging` | 제목+썸네일을 한 세트로 확정 | 제목 1개 선택 + 썸네일 문구/컨셉 확정 |
| `filming` | 촬영 | 촬영본 확보 |
| `editing` | 편집·챕터 | 최종 렌더 |
| `ready` | 작업 완료. 렌더 끝, 업로드만 남음 | 유튜브 예약 |
| `scheduled` | 업로드 예약 완료 | 게시됨 |
| `published` | 공개됨 | 48시간·7일 지표 기록 |
| `reviewed` | 회고 완료 | — |
| `dropped` | 보류/폐기 (사유를 notes에) | — |

- 쇼츠(`format: "short"`)는 `research`, `packaging` 을 건너뛸 수 있다.
- 패키징은 대본 *전에* 해도 된다. 제목·썸네일로 클릭할 이유가 안 나오면 만들 가치도 없는 영상이다.

## 핵심 원칙: 약속 일치
훅(첫 15~30초)·제목·썸네일은 **같은 약속**을 해야 한다. 썸네일 문구는 제목을 반복하지 않는다(다른 단어, 같은 약속). 어긋나면 낚시로 읽히고 리텐션이 무너진다.

## KPI (`VideoMetrics` 필드)

| key | 정의 |
|---|---|
| `impressions` | 썸네일 노출 수 |
| `ctr` | 노출 클릭률 (%, 0~100) |
| `views` | 조회수 |
| `avdSeconds` | 평균 시청 지속 시간(초) |
| `avgPercentViewed` | 평균 시청 비율 (%) |
| `retention30s` | 30초 시점 잔존율 (%) |
| `subsGained` | 이 영상으로 늘어난 구독자 |
| `returningViewersPct` | 재방문 시청자 비율 (%) |

해석 규칙:
- CTR × 만족 시청 = 노출 1회의 가치. CTR 높고 AVD 낮으면 낚시 신호.
- 노출이 늘면 CTR은 자연히 떨어진다. CTR 하나만 보고 판단하지 않는다.
- 아웃라이어 = 해당 채널 *자기 중앙값* 대비 조회수 배수. 원조회수로 비교하지 않는다.
- 아래 수치는 커뮤니티 경험치이며 검증된 기준이 아니다. 말할 때 "대략적 경험치"라고 밝힌다: CTR 4~8% 양호 / 3% 미만 약함, 30초 잔존 70%+ 양호, 평균 시청 비율 40~50%+ 강함.

## 계획 단위
- **필러(pillar)**: 채널 주제 3~5개. 모든 영상은 정확히 하나의 필러에 속한다.
- **주간 슬롯 역할**: `anchor`(공들인 롱폼 1) · `cheap`(기존 자료 재활용 롱폼, 선택) · `short`(앵커에서 잘라낸 쇼츠).
- 12주 동안 유지할 수 있는 주기를 고른다. 의욕 최고치가 아니라 바쁜 주 기준.
